# Olitas para Android

Descargas de la app Olitas para Android.

## Descargar

[Descargar la última versión (olitas.apk)](https://github.com/anabotha/olitas-descargas/releases/latest/download/olitas.apk)

Todas las versiones están en la sección [Releases](https://github.com/anabotha/olitas-descargas/releases).

## Cómo instalarla

1. Abrí el link de arriba desde el celular Android.
2. Cuando termine la descarga, abrí el archivo `olitas.apk`.
3. Si Android lo pide, permití instalar apps de origen desconocido para el navegador.
4. Tocá Instalar.

Android puede avisar que el archivo podría ser dañino. Es un aviso normal para apps que no vienen de la Play Store.

## Requisitos

- Solo Android. En iPhone no se pueden instalar archivos APK.
